# 3_Machine_Learning_Scripts

## Purpose
Machine-learning preparation, model training, and plotting workflows for cancer-vs-normal, cancer-type, and subtype analyses.

## Subfolders
- `1_Select_and_PCA_transform_features/`: build train/validation matrices and PCA transforms.
- `2_Shell_and_R_scripts_for_running_ML_pipelines_PE_data_cancer_vs_normal_classifier/`: CN classifier runners and implementation scripts.
- `3_Scripts_for_running_ML_pipelines_PE_data_cancer_type_or_subtype/`: Python cancer-type/subtype classifiers and run tables.
- `4_Machine_learning_plotting_scripts/`: result aggregation and figure-generation scripts.

## Inputs
- Processed methylation/fragmentomics feature matrices and metadata.

## Outputs
- Model objects, CV predictions, ROC/kappa summaries, and publication-ready plots.
